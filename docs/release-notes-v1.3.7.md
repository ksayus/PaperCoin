# PaperCoin v1.3.7

## 更新功能

### 统计页（新增，侧边栏第四项）

- **分类占比圆环图**：按分类看钱花到哪儿去了，圆心显示总支出与笔数。分段按金额降序，起点固定在 12 点方向，段间留缝避免相邻同色。
- **分类排行榜**：金额、笔数、占比一列排开，条形长度取"相对第一名"的比例。
- **分类明细**：点排行行、点图例色块，或用"分类明细"右侧的下拉选一个分类，列出它的**全部**流水，并给出笔数、合计与占全部支出的比例。这块刻意不受时间范围限制 —— 想核对某个分类的完整流水时，按范围过滤反而碍事。
- **近 12 个月支出趋势**：柱高取"相对最高月"的比例，最高月单独标注。
- **时间范围切换**：本月 / 本年 / 全部。趋势图刻意不受范围限制——趋势本身就是跨范围的视图，跟着范围走只会剩一根柱子。
- **导出 CSV**：按当前范围导出明细与合计，UTF-8 带 BOM，Excel 直接打开不乱码。导出的位置会在界面上给出完整路径。

### 主题风格（新增）

明暗与风格拆成**两个独立维度**，组合出 6 套调色板：

- **明暗**：跟随系统 / 暗色 / 亮色
- **风格**：
  - **经典** —— 项目原本的观感，圆角卡片 + 柔和阴影
  - **Windows** —— Fluent 观感：纯色不透明的中性灰阶表面，层级靠色阶而不是阴影拉开，强调色用系统蓝 `#0078D4`
  - **液态玻璃** —— 半透明材质 + 发丝高光描边：面板透出背板形成玻璃感，边框用高 Alpha 白色当高光

设置页「外观」一组里有两行分段控件，各自独立选择。切换时颜色照旧走 300ms 过渡。

**液态玻璃用的是真·背部高斯模糊。** 模糊不由 WPF 算（`BlurEffect` 只能模糊元素自己的内容），而是交给 DWM 的系统背板（Acrylic）：它拿得到屏幕内容，把窗口背后按高斯核模糊后填进窗口背景，所以窗口拖到不同内容上时玻璃颜色会跟着变，而不是一层固定的半透明色。

这带来一个不可避免的取舍：系统背板只对**非分层窗口**生效，而窗口原本是 `AllowsTransparency`（自绘标题栏与圆角需要它）。所以液态玻璃风格改为非分层窗口 —— 圆角交给 DWM、阴影由系统给；其余风格不受影响，仍是分层窗口 + WPF 圆角与阴影。

模糊层之上另有一层随主题走的明度层，把模糊结果的明度钉住。没有它，窗口压在浅色内容上时玻璃面板上的白字会读不清（实测只有 2.8:1）。

> 玻璃风格的正文对比度门槛取 4.0:1 而非 WCAG AA 的 4.5:1：模糊结果可能是纯白，而玻璃又必须让模糊透出来，两者在 4.5 上不可兼得。实测最坏情形 4.2:1。

### 日历账单

- **明细可以改和删了**，日 / 月 / 年三种粒度都一样：点卡片开编辑面板，点卡片右上角的垃圾桶删掉这一笔。与今日账单共用同一个编辑面板、同一套手势与动效。
- **三种粒度右下角都有 ＋**。新增的默认日期对每种粒度都有唯一答案：日视图是当前定位那天；月 / 年视图下当天若落在当前范围内就用当天，否则用范围内的第一天（当月 1 号 / 1 月 1 日）。以前月 / 年视图下这个按钮是藏起来的，因为"记到哪一天"没有唯一答案 —— 现在有了，所以按钮一直可用。

> 月 / 年视图的删除不能像今日账单那样整片回写：那个列表**混了多天**，拿它去覆盖写会把列表里没有的日期当成"这天清空了"。所以删除走按 Id 的单笔删除，只动那一笔所属的日期文件。有断言逐日核对其它日期不受影响。

### 自动更新（新增）

设置页「自动更新」开关打开后，**启动时在后台查一次新版本**，结果直接显示在设置页那一行；也可以随时点「检查」手动查。查到之后点「下载并安装」就会下载安装包并启动安装程序。

- 更新源可选 **GitHub** 或 **Gitee**。
- 设置页会直接列出新版本的更新内容（取前几行，完整说明在发布页）。
- 检查在后台进行，**不阻塞窗口显示**；网络不通、超时、限流都只会给出一句话，不影响程序使用。
- 下载到临时目录，不碰程序目录。

> 如果你看到的是「查询被拒绝（HTTP 403）」，那是 GitHub 对匿名调用的限流，过一会儿再试即可。

### 图标

- 换上新的图标字体（22 个码位，新增房子、刷新、统计/分析、拼图四个字形），统计项改用真正的"统计/分析"图标。

### 分类配色

- 每个分类有自己固定的颜色，且**跨时间范围、跨重启都一致**（按分类名做稳定哈希，不是按出现顺序分配，也不受进程随机化影响）。
- 同一套颜色同时用在圆环、图例、排行榜条形，以及今日页与日历页的流水卡片色条上，看一处就知道是同一个分类。
- 颜色定义在主题字典里，切换暗色 / 亮色时跟着一起过渡。

### 安装程序

- **首次安装可以选择安装目录**（默认 `C:\Program Files\PaperCoin`）。
- **升级时自动沿用它上次装的位置**，不再让用户改——路径漂移会让账"看不见"。

## 优化

- **动效统一**：全项目的时长与缓动收敛到一套具名常量（`Views/Motion.cs`），按"直接反馈 / 状态切换 / 带过冲收尾 / 图表展开"四档使用。按钮回弹统一成"去程 + 回程"两段，终点能精确落回静止值，不会停在超调值上。
- **每次进页面都重播入场动画**：页面实例被主窗口长期缓存，控件不会重建，所以每个"本次进场只播一次"的标志都必须在进场时复位。补齐了统计页的三块图表、今日页与日历页的空状态提示、日历页年视图的整片入场。此前这些动画只在本次进程第一次进页面时看得到。
- **分类明细挪到圆环正下方**（原来排在页面最下面、排行之后）。选中分类后它虽然在更新，却常常在屏幕之外，看起来像"点了没反应"。现在它紧跟圆环、排在排行之前，并且补了断言：明细区块的纵坐标必须落在首屏可视高度之内。
- **从下拉框选分类现在能看明细了**。这是一条真正走不通的路径：下拉框的 `SelectedItem` 绑成 `Mode=OneWay` 而目标属性的 setter 是私有的，用户在选择器里选会被绑定**静默丢弃**。点排行行、点图例走的是命令，所以只有"从下拉框选"这一个入口是坏的。
- **"查看全部 / 收起"之后排行条的颜色不再消失**。那两下会把 `VisibleRankRows` 换成新列表，`ItemsControl` 因此**重建全部行容器**，`RankBar` 的宽度被重置回模板里的 `Width="0"`；此前没有任何东西再触发动画，于是前景条与背景条宽度都是 0，整片看起来就是没颜色了。现在这两下会重播排行条动画。
- 补充的状态反馈动效：合计金额变化时脉冲一次、＋ 号与粒度按钮悬浮抬起、开关滑块切换时先压扁再回弹、圆环与柱状图依次展开。
- **窗口放大到 480×640**，统计页的图表与排行不再被挤扁。
- 数据目录从程序目录搬到 `%APPDATA%\PaperCoin`，配合"路径可选"：程序装在 `Program Files`（普通权限不可写）也不会写不进去，用户改安装位置也不会丢账。
- **账单自动迁移**：首次启动把 1.2.x 留在旧安装目录下的账单复制到新数据目录。是复制不是移动，旧目录原样保留；失败只记日志，不影响启动。
- 导出目录加入 `.gitignore`。

## Bug 修复
- **安装包装出来打不开**（一启动就崩，连日志都没写）。根因在打包方式：安装项目里 `PaperCoin.dll` 取自 `publish` 目录，而 `PaperCoin.exe` 取自 `obj\Release` 下的中间产物，两者一旦不同步，包里的 exe 与 dll 就不是同一次构建的产物 —— 而 `obj` 里可能残留上一次失败构建的 `*.g.cs`（编出来的主窗口里 `GlassBackdrop` 注册了两遍，XAML 加载直接抛 `XamlParseException`）。

  现在固定成"清 obj/bin → `publish` → 只打包"，中间不插任何构建；并且加了一道发布前核验：把包里的程序集与 `publish` 逐字节比哈希，再从包里把 exe 抽出来实际启动一次。**版本号对、文件大小对，都不等于能跑。**

- **圆环图完全不显示**：圆环的弧线是用 `AddVisualChild` 手工挂上去的可视子元素，但从来没有对它们调过 `Arrange`，`RenderSize` 一直是 0×0，渲染时被整批跳过 —— 界面上一个环都看不到，而且不报任何错。改成继承 `Canvas`，把弧线作为 `Children` 交给布局系统摆放。
- **侧边栏指示器点"统计"时停在"设置"上**：新增的导航枚举值没有加进 `RepositionIndicator` 的 switch，落进了默认分支（指向设置按钮）。四个导航项现在都显式列出；冒烟测试也从"指示器动了"改成"指示器必须落在它自己那个按钮上"。
- **统计页切换时间范围不生效**：范围切换不走索引版本号，会被"没变化就跳过重算"的判定挡掉，表现为按钮高亮变了、数字还是上一个范围的。范围切换改为强制重算。
- **圆环在窗口尺寸变化后消失**：尺寸一变就要重建弧线，而新建弧线的描边宽度是动画起点 0，不会有人再来推进它。展开过之后再重建现在直接落到最终宽度。
- **"这个范围内没有支出"在明明有支出时也显示**，还叠在圆心金额上：绑定用错了属性（`HasExpense` 应为 `HasNoExpense`）。
- **下拉框选中项的文字是黑色**，暗色主题下几乎看不见。两个原因叠在一起：`ComboBoxThemed` 模板里的 `ToggleButton` 从来没引用 `ComboToggle` 样式（一直用系统默认模板，不跟随主题）；而且 `ContentPresenter` 不会把 `ComboBox` 的 `Foreground` 传给它生成的 `TextBlock`，必须显式给。设置页"更新源"下拉框一并修好。
- **装了旧版之后装不上新版**：重建同一个版本号时沿用了旧的 `ProductCode`，Windows Installer 认定"同一个产品已安装"，而文件版本又相等，覆盖也被跳过 —— 双击安装毫无反应。发布时换新的 `ProductCode`；冒烟测试现在会检查新 `ProductCode` 未被本机已安装的其它版本占用。
- 排行行从"代码后置合成鼠标事件"改成标准的 `Button` + `Command` 绑定：原来的写法在合成事件与真实点击之间隔着命中测试、按下状态等一串条件，出问题时无法从现象判断是绑定坏了还是事件没送到。

## 安装包

- `PaperCoin.msi`（约 1.15 MB）与 `setup.exe`
- 需要 .NET 10 桌面运行时；安装时会提权（每机器安装）
- **升级**：会自动认出上次的安装位置并原地升级，不需要手动卸载旧版（`UpgradeCode` 未变）
- **从 1.2.x 升级**：首次启动时把旧目录下的账单复制到 `%APPDATA%\PaperCoin`（复制不是移动，旧目录原样保留）
- 本版起可在设置页打开**自动更新**，之后有新版本会直接显示更新内容并支持一键升级
