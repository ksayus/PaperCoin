# PaperCoin v1.3.0

## 更新功能

### 统计页（新增，侧边栏第四项）

- **分类占比圆环图**：按分类看钱花到哪儿去了，圆心显示总支出与笔数。分段按金额降序，起点固定在 12 点方向，段间留缝避免相邻同色。
- **分类排行榜**：金额、笔数、占比一列排开，条形长度取"相对第一名"的比例。
- **分类明细**：点排行行、点图例色块，或用"分类明细"右侧的下拉选一个分类，列出它的**全部**流水，并给出笔数、合计与占全部支出的比例。这块刻意不受时间范围限制 —— 想核对某个分类的完整流水时，按范围过滤反而碍事。
- **近 12 个月支出趋势**：柱高取"相对最高月"的比例，最高月单独标注。
- **时间范围切换**：本月 / 本年 / 全部。趋势图刻意不受范围限制——趋势本身就是跨范围的视图，跟着范围走只会剩一根柱子。
- **导出 CSV**：按当前范围导出明细与合计，UTF-8 带 BOM，Excel 直接打开不乱码。导出的位置会在界面上给出完整路径。

### 图标

- 换上新的图标字体（22 个码位，新增房子、刷新、统计/分析、拼图四个字形），统计项改用真正的"统计/分析"图标。

### 分类配色

- 每个分类有自己固定的颜色，且**跨时间范围、跨重启都一致**（按分类名做稳定哈希，不是按出现顺序分配，也不受进程随机化影响）。
- 同一套颜色同时用在圆环、图例、排行榜条形，以及今日页与日历页的流水卡片色条上，看一处就知道是同一个分类。
- 颜色定义在主题字典里，切换暗色 / 亮色时跟着一起过渡。

### 安装程序

- **首次安装可以选择安装目录**（默认 `C:\Program Files\PaperCoin`）。
- **升级时自动沿用它上次装的位置**，不再让用户改——路径漂移会让账"看不见"。

## 优化

- **动效统一**：全项目的时长与缓动收敛到一套具名常量（`Views/Motion.cs`），按"直接反馈 / 状态切换 / 带过冲收尾 / 图表展开"四档使用。按钮回弹统一成"去程 + 回程"两段，终点能精确落回静止值，不会停在超调值上。
- 补充的状态反馈动效：合计金额变化时脉冲一次、＋ 号与粒度按钮悬浮抬起、开关滑块切换时先压扁再回弹、圆环与柱状图依次展开。
- **窗口放大到 480×640**，统计页的图表与排行不再被挤扁。
- 数据目录从程序目录搬到 `%APPDATA%\PaperCoin`，配合"路径可选"：程序装在 `Program Files`（普通权限不可写）也不会写不进去，用户改安装位置也不会丢账。
- **账单自动迁移**：首次启动把 1.2.x 留在旧安装目录下的账单复制到新数据目录。是复制不是移动，旧目录原样保留；失败只记日志，不影响启动。
- 导出目录加入 `.gitignore`。

## Bug 修复

- **圆环图完全不显示**：圆环的弧线是用 `AddVisualChild` 手工挂上去的可视子元素，但从来没有对它们调过 `Arrange`，`RenderSize` 一直是 0×0，渲染时被整批跳过 —— 界面上一个环都看不到，而且不报任何错。改成继承 `Canvas`，把弧线作为 `Children` 交给布局系统摆放。
- **侧边栏指示器点"统计"时停在"设置"上**：新增的导航枚举值没有加进 `RepositionIndicator` 的 switch，落进了默认分支（指向设置按钮）。四个导航项现在都显式列出；冒烟测试也从"指示器动了"改成"指示器必须落在它自己那个按钮上"。
- **统计页切换时间范围不生效**：范围切换不走索引版本号，会被"没变化就跳过重算"的判定挡掉，表现为按钮高亮变了、数字还是上一个范围的。范围切换改为强制重算。
- **圆环在窗口尺寸变化后消失**：尺寸一变就要重建弧线，而新建弧线的描边宽度是动画起点 0，不会有人再来推进它。展开过之后再重建现在直接落到最终宽度。
- **"这个范围内没有支出"在明明有支出时也显示**，还叠在圆心金额上：绑定用错了属性（`HasExpense` 应为 `HasNoExpense`）。
- 排行行从"代码后置合成鼠标事件"改成标准的 `Button` + `Command` 绑定：原来的写法在合成事件与真实点击之间隔着命中测试、按下状态等一串条件，出问题时无法从现象判断是绑定坏了还是事件没送到。

## 安装包

- `PaperCoin.msi`（约 1.15 MB）与 `setup.exe`
- 需要 .NET 10 桌面运行时；安装时会提权（每机器安装）
- **从 1.2.x 升级**：会自动认出旧安装位置并原地升级；首次启动时把旧目录下的账单迁移到 `%APPDATA%\PaperCoin`
