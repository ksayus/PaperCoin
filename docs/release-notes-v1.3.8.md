# PaperCoin v1.3.8

## 亮点：局域网账单同步

Windows 与 Android、Android 与 Android 现在可以在同一局域网自动同步账单。

- **发现与配对**：UDP 47831 自动发现；TCP 47832 传输（端口占用时自动换端口并在发现包中广播实际端口）。两端设置同一个 6–12 位同步码即可配对，同步码不会明文发送。
- **三方合并**：按上次成功同步的基线传播新增、修改、删除；只有两边都改、或一边删除另一边修改时才产生冲突。
- **逐条冲突处理**：冲突页并排显示本机与对方版本，每一条都必须选“保留本机 / 保留对方”才能应用；“取消同步”不会写入任何一侧。
- **自动同步**：首次手动同步后记住设备；Android 在前台、Windows 在程序运行期间每 20 秒自动同步已配对设备，只有 deviceId 较小的一端主动发起。
- **并发保护**：交换快照后、落盘前校验整份账单快照哈希；用户在同步期间改了账，整次同步作废并提示重试，不会半写覆盖。
- **状态独立**：同步基线与设备信息保存在各自的 `Sync/papercoin-sync.json`，不写进账单 JSON。

完整协议、哈希向量与合并规则见 [lan-sync-protocol.md](lan-sync-protocol.md)。

## Windows

- **安装包回到项目 Setup 生成的 MSI**：`PaperCoin.msi` 与 `setup.exe`，不再使用 NSIS 替代。
- 修复 VS 2026 加载旧 `.vdproj` 时直接取消的问题：移除遗留的 `"VSVersion" = "3:800"`，现在 `PaperCoin.Setup` 可正常构建。
- 版本升到 **1.3.8**，换用新的 `ProductCode`/`PackageCode`，`UpgradeCode` 保持不变，可原地升级 1.3.7。
- 首次安装可选目录；升级沿用上次安装位置；开始菜单、桌面快捷方式和卸载项保持原有行为。
- **自动刷新**：同步完成后，当前可见的今日 / 日历 / 统计页会重新读取磁盘，不会停留在旧数据。
- 新增“局域网同步”设置行、同步管理窗口和冲突窗口。

## Android

- Android 版同步更新到 **1.3.8 / versionCode 10308**。
- 新增“设置 → 局域网同步”：启用、同步码、设备名、自动同步、发现设备、已配对设备、手动 `主机:端口`。
- 冲突页逐条选择保留哪一边；“取消同步”不写入任何数据。
- 同步完成会刷新当前页面；应用退到后台停止监听，回到前台恢复。
- 仍支持 ZIP 备份、桌面版 `Bills` 文件夹导入、统计 CSV、主题与六套调色板。

## 修复与优化

- 同步服务端与客户端都在落盘前校验快照哈希，并校验写入后的最终哈希；失败会回退为“下次同步收敛”，不会静默覆盖。
- Android 同步状态文件加载时统一同步码大小写，并清理非法/空同步码。
- Android 的今日 / 日历 / 统计 ViewModel 监听仓库 revision，自动同步拉取的新账单会即时显示。
- Windows 主窗口订阅 `SyncCompleted`，只刷新当前可见页面，不重建整个界面。
- MSI 文件表已确认包含 1.3.8 的 `PaperCoin.exe`、`PaperCoin.dll`、`PaperCoin.Service.dll`，并确认同步类型已编入程序集。

## 安装与升级

### Windows

- 需要 **.NET 10 桌面运行时**。
- 推荐直接双击 `PaperCoin.msi`；也可以运行 `setup.exe`（需与 MSI 同目录）。
- 安装需要管理员权限（每机器安装）。
- 从 1.3.7 升级会复用原安装位置；`%APPDATA%\PaperCoin` 中的账单与配置保留。1.2.x 留在旧程序目录的账单由应用首次启动迁移。
- 本机若还残留更老的 1.2.2 MSI 记录，1.3.8 的升级链不会动它；不需要时可在“应用和功能”里手动卸载。

### Android

- 安装 `PaperCoin-1.3.8-android.apk`。
- 首次安装需要允许“安装未知应用”；覆盖安装 1.3.7 时数据保留。

## 验证

- Android：**65 / 65** 单元与 Robolectric 截图测试通过；Release APK 使用 v2 签名。
- Windows：`dotnet build PaperCoin.sln` 0 错误；同步协议测试 **14 / 14**；UI 冒烟测试 **33 / 33**。
- MSI：管理员解包成功；文件表 24 个文件，核心程序集版本 `1.3.8.0`；解包后的 `PaperCoin.exe` 已实际启动。
- 未进行真实 Android 手机与 Windows 电脑的同网配对测试；跨端兼容性由完全一致的哈希/HMAC 向量、两端各自的 TCP 回环和 DTO 审查覆盖。

## 已知限制

- 同步只在可信局域网使用；传输没有 TLS 加密，同网段嗅探者可以看到账单内容，同步码只用于阻止误连。
- Android 只在应用前台监听；没有常驻前台服务。
- Windows 首次监听时 Windows Defender 防火墙可能询问，需要放行专用网络的 TCP 47832 / UDP 47831。
- 冲突后的“取消同步”不会应用任何一侧的改动；非冲突改动也不会先落一半。
